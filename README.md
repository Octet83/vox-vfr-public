## Corrections v1.4.1

- **Voix OpenAI et ElevenLabs à nouveau opérationnelles.** Depuis la v1.4.0, les voix cloud ne produisaient plus aucun son : en vol, l'application basculait sur la voix Windows sans prévenir clairement, et le bouton *Paramètres → Voix → Tester la voix* affichait un message d'erreur technique. Les voix Windows n'étaient pas concernées.

Si vous utilisez une clé OpenAI ou ElevenLabs, cette mise à jour est indispensable.
